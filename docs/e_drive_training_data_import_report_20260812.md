### 旧角点 bbox 约定差异

新增数据的 15678 个椎体实例中，bbox 全部精确等于四角点的最小外接框。

旧数据的 12630 个实例中：

- 2094 个 bbox 能完整包含四角点；
- 10536 个 bbox 有角点轻微位于框外；
- 最大超出量中位数为归一化坐标 0.002320；
- 2213 个实例超出量大于 0.005；
- 195 个实例大于 0.01；
- 最大值为 0.025931。

该现象覆盖全部 743 份旧文件，是旧数据生成方式的系统性差异，不是本次导入产生。Ultralytics 不会因关键点略在 bbox 外而拒绝标签，但 bbox 面积参与关键点损失尺度计算，因此建议在下一次角点训练前单独评估是否把旧 bbox 重算为四点外接框。

## 图像域与评估风险

- 新增图像全部为可解码 PNG，但同时包含灰度、RGB 和 RGBA；旧图主要为灰度 PNG。
- 新图分辨率和长宽比分布更宽。抽查最小分辨率及最宽画幅样本，仍为可辨认的正位全脊柱影像，未发现明显错误模态。
- 六点 train 中旧/新来源为 533/662，val 为 77/72，test 为 75/75；三个分区均覆盖旧、新来源。
- 角点新增数据占 train 的 59.5%，角点 val/test 仍全部来自旧数据。

因此六点 val/test 已能同时评价旧、新数据域；角点 val/test 仍只能评价旧数据域。角点后续若重新划分，也应按患者而不是按图像划分。

两个任务之间有 741 张精确相同的新增图像。这是两个独立模型复用相同正式病例，不属于单个任务内部重复或 split 泄漏。
