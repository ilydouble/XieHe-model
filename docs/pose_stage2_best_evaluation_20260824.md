# 六点 Pose 阶段二 `best.pt` 评测结论（2026-08-24）

## 结论

当前阶段二微调 `best.pt` 没有带来改进，不建议采用两阶段上线。175 张独立 test 上，一阶段平均误差为 29.850 px，两阶段为 38.800 px，增加 8.949 px（约 30.0%）；149/175 张恶化，只有 25 张改善，另有 1 张阶段二未检出而回退。

## 公平比较边界

- 数据：`datasets/pose_data/images/test` 与 `labels/test`，175 张患者隔离原始图。
- 一阶段：`best_performance-5/weights/best.pt`，SHA-256 `cf4af724d5707bf888f826225bcc5924f2986b8b44ab1d69c201de001a9740e7`。
- 二阶段：`stage2_existing_roi_v1/weights/best.pt`，SHA-256 `0e2c5f938306db7f772bc7d2e9a7b48e63cb7f4dd260e554959270a33e2a09da`。
- 参数：`imgsz=800`、候选置信度 `0.25`、预测 ROI 外扩 `20%`，CPU 顺序推理。
- 流程：原图一阶段预测框 → 预测 ROI → 独立阶段二权重预测六点 → 回写原图坐标。两阶段结果不是 GT 框评测。

## 主要指标

| 指标 | 一阶段 | 两阶段 `best.pt` | 变化 |
|---|---:|---:|---:|
| 平均误差 | 29.850 px | 38.800 px | +8.949 px |
| 中位误差 | 21.639 px | 29.047 px | +7.408 px |
| P90 误差 | 64.947 px | 81.860 px | +16.913 px |
| PCK@20 px | 46.38% | 31.52% | -14.86 pp |
| PCK@2% 对角线 | 95.81% | 94.19% | -1.62 pp |
| 改善/不变/恶化 | — | 25 / 1 / 149 张 | 明显偏向恶化 |

来源分组也没有例外：`eap_` 98 张从 36.087 增到 46.798 px，旧来源 77 张从 21.913 增到 28.620 px。

纵向偏差在阶段二后反而变大并反向：肩点平均 `dy` 从 +0.536 px 变为 +22.621 px，下方四点从 +1.333 px 变为 -6.869 px，整体跨度偏差从 +0.797 px 变为 -29.490 px。这里 `dy=预测y-标注y`，正值表示预测更低，负值表示预测更高。因此阶段二主要表现为肩点过低、下方点过高、上下跨度收缩，不像坐标回写或缩放错误，更符合 ROI 训练分布与实际预测 ROI 不一致造成的模型偏差。

CPU 模型推理时间从一阶段平均 136.888 ms 增至两阶段总计 276.495 ms，额外增加约 138 ms，顺序吞吐约 3.62 FPS。精度下降的同时耗时约翻倍。
